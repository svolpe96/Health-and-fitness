# Mini-cut — strength and muscle retention
Start assumption: Monday November 30, 2026 (shift if cut begins earlier). Duration 3 weeks, optional fourth. Separate from program/current; original program and raw logs remain unchanged.
Baseline: Week 8 planned, latest confirmed Week 7. November 9 bench 280x5x3 @7/7/7; November 16 bench 285x4/4/4/3 @9/9/9/10; November 20 squat 425x5x3 @7/7/8 with belt/sleeves, no groin pain reported; November 17 sumo 425x3x3 @5/5/6; November 20 close grip 250x6x3 @7/7/7. ## Volume decision
Week 8 four core days: 19 main-lift sets, 34–35 accessory sets including optional work (53–54 total); excluding optional work 43 total. Mini-cut four core days: 18 main sets, 23 accessory sets, 41 total (23–24% below full planned volume, only ~5% below required-only plan). Optional Saturday reduced from 7 to 5 sets; total 46 vs 60–61 (~23–25%). Actual completed volume varies; do not force an increase over tolerated workload. Week 7 had only 3 sessions; skip optional work first. Maintain squat twice, bench three times, sumo once; optional extra technique exposures.
## Rules
Main lifts RPE 7–8 ceiling; secondary bench/squat and returning sumo may be 6–7 or lower, never force load to hit RPE. No grinders, failure, added sets or PRs. Accessories RPE 7–8, last set only. Rest 3–5 minutes main lifts and 1–3 minutes accessories. Loads are starting suggestions in lb, not completed results. Keep equipment/technique consistent. If first set exceeds 8 or technique degrades, reduce 2.5–5%; if still above cap, stop or remove remaining set. If warmups unusually hard or recovery poor, omit optional work and one accessory set per movement as needed. If two consecutive exposures deteriorate or soreness persists >48–72h, reduce one main set in affected lift and reassess deficit. If groin pain returns or worsens or changes mechanics, stop/modify squat or sumo; seek evaluation if persistent. Track during/after/next day. No makeup work.
## Progression
Week 1 calibrate. Weeks 2–3 repeat successful loads and reps; no obligatory increases. Only if all sets <=7, technique consistent and recovery stable across two exposures, consider +5 lb bench or +5–10 lb squat/sumo (sumo only if symptom-free); otherwise hold. Week 4 optional only if recovery and weight trend support it; reduce accessory sets further if needed or end cut. Compare same load/reps/equipment and RPE, not historical maxes. Log every main set RPE, accessory last-set RPE, morning weight, sleep, hydration 1–5, energy 1–5; add soreness and groin response. No caffeine or training time. Keep using shared raw CSV with actual dates only, and separate weekly checklists here.
## Nutrition and exit
At ~166 lb, 1.5 lb/week is ~0.9%/week, aggressive given previous diet/groin history. Prefer 0.75–1.25 lb/week if performance deteriorates; do not force loss beyond 1.5 or chase water shifts. Protein ~150–180 g/day, adequate dietary fat (~45–60 g/day), remaining calories carbohydrate, prioritize pre/post training carbs; consistent hydration/sodium and 7–9 h sleep. Track daily morning weight and 7-day averages; no calorie prescription without current intake/maintenance data. If persistent strength decline, low energy, dizziness, or recurrent injury, reduce deficit or stop cut. No dehydration. Return to maintenance calories after 3–4 weeks; first week hold cut loads, restore ~half removed accessory sets; second week restore remaining sets if RPE/recovery stable, then resume progression in program/current with a new week based on current data rather than blindly repeating old prescriptions.
